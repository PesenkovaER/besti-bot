# Бести Bot 🤍💅🧠

Telegram-бот с искусственным интеллектом, который может общаться в трёх разных стилях: милая подруга, токсичная девушка или нейтральный аналитик.

## О проекте

Бести — это не просто обычный бот. Это персонализированный собеседник, который адаптируется под настроение пользователя. Хочешь нежности и поддержки? Выбирай режим "Милашка". Хочешь правду-матку и сарказм? Включай "Токсика". Нужен холодный разум без эмоций? Режим "Факты" к твоим услугам.

Бот построен на базе DeepSeek V3 через OpenRouter API и написан на Python с использованием библиотеки Aiogram.

## Возможности

- 🤍 **Няшка-милашка** — эмоциональная, добрая, всегда поддержит
- 💅 **Токсик** — саркастичная, острая на язык, с юмором
- 🧠 **Факты** — спокойная, логичная, только по существу
- 🔄 Мгновенная смена режима без перезапуска
- 🧹 Очистка памяти по команде
- 📝 Запоминает факты из диалога и сохраняет контекст

## Технологический стек

- Python 3.10
- Aiogram 3
- OpenRouter API (DeepSeek V3)
- Git
